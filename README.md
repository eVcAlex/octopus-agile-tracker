# Octopus Agile Tracker

A simple React dashboard to track Octopus Energy Agile electricity prices in different regions. Built with **React**, **TypeScript**, **Chakra UI**, and **Phosphor Icons**.

---

## Features

- View **today's and tomorrow's electricity rates** by region.
- Display **statistics**: Minimum, Maximum, Average, and Current Price.
- **Native select** for switching regions.
- **Dark/light mode** toggle.
- Refresh data manually.
- Mobile-friendly and responsive.
